# Prelim Activity 01: Codac Logistics Delivery & Fuel Auditor
A console-based C# application for tracking daily fuel expenses and delivery performance of delivery vehicles over a 5-day work week.

## Project Overview

This tool was developed for **Codac Logistics** to help delivery drivers and the accounting department:
- Track daily fuel expenses
- Validate delivery distance data
- Calculate fuel efficiency ratings
- Generate comprehensive financial summaries

## Features

- **Driver Profile Management**: Collect and validate driver information and weekly fuel budgets
- **Distance Validation**: Input validation ensuring distances are within operational range (1.0 - 5000.0 km)
- **Daily Expense Tracking**: Store and manage fuel costs for 5 working days
- **Performance Analysis**: 
  - Calculate average daily fuel expenses
  - Determine fuel efficiency ratings (High, Standard, or Low)
  - Compare actual spending against budget
- **Audit Reports**: Generate formatted reports with detailed breakdowns and recommendations

## Concepts Demonstrated
- Data Types: `string`, `int`, `double`, `decimal`, `bool`
- Input/Output: `Console.ReadLine()` and String Interpolation
- Validation: `while` loops for input validation
- Data Structures: 1D Arrays
- Control Flow: `for` loops and `if/else` statements
